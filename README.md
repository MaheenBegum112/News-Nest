# 📰 NewsNest

A modern and responsive news application built with **React.js, Vite, and Tailwind CSS**. NewsNest fetches real-time news using the GNews API, allowing users to browse top headlines, filter news by category, and search for specific articles.

## 🚀 Live Demo

**[🌐 View NewsNest Live](https://news-nest-blush.vercel.app/)**

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript
* Axios
* GNews API
* FastAPI
* Git & GitHub
* Vercel

## ✨ Features

* 📰 Latest news headlines
* 🔍 Search news by keyword
* 🗂️ Browse news by category
* 📱 Responsive design
* 🔗 Read the full article from the original source
* ⚡ Dynamic news fetched from an API
* ♻️ Reusable React components



## ⚙️ Run Locally

```bash
git clone https://github.com/MaheenBegum112/News-Nest.git
cd News-Nest
npm install
npm run dev
```

## 🔑 Environment Variable

Create a `.env` file:

```env
GNEWS_API_KEY=YOUR_API_KEY
```

Never commit your actual API key to GitHub.
