# 📰 NewsNest

A modern and responsive news application built with **React.js**, **Vite**, and **Tailwind CSS**.
NewsNest fetches real-time news using the **GNews API**, allowing users to browse top headlines, filter by category, and search for news articles.

---


## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios
- GNews API

---


## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/MaheenBegum112/News-Nest.git
```

2. Navigate to the project folder

```bash
cd News-Nest
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file in the project root

```env
VITE_GNEWS_API_KEY=YOUR_API_KEY
```

5. Start the development server

```bash
npm run dev
```
